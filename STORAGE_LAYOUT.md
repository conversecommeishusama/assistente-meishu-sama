# Goshinsho Storage Layout

This file documents the intended project storage layout after the cleanup.

## Runtime Code

- `app.py`: Flask entrypoint used by Gunicorn.
- `goshinsho/`: application package.
- `templates/`: HTML templates.
- `static/`: frontend assets.
- `glossario.json`: glossary loaded by search/AI services.
- `logo.png`: active logo served by the app.
- `static/downloads/`: optional APK download files served by Flask when present.
- `.env`: local production secrets, not versioned.
- `venv/`: active Python environment used by systemd, not versioned or backed up.

## Source Data for Rebuilds

- `textos_portugues/`: Portuguese source texts.
- `textos_japones/`: Japanese source texts.
- `data/publication_sources/`: clean derived collection organized by publication source/date.
- `data/support_tickets/`: local support data.

These directories are required for rebuilds or local operation, but are not intended to be versioned in Git. They are preserved by project backups.

## Generated Artifacts

- `data/clean_corpus/`: regenerated by `scripts/build_clean_large_indexes.py`.
- `experiments/uploaded_indexes/`: active FAISS/pickle indexes used by the app.
- `experiments/rebuilt_large_indexes/`: temporary staging directory during rebuilds.
- `exports/`: manual export packages, kept out of Git.
- `logs/*.jsonl`, `logs/*.log`, `logs/*.tmp`: operational logs.

## External Trash

Items not used by the app but kept for possible recovery are moved outside the project:

- `/var/backups/goshinsho/trash/20260618T012650Z-project-cleanup/`

This currently contains old logo variants, prior cleanup quarantine, restored bytecode artifacts, the exported collection archive, and an old benchmark result.

The old `android-app/` and `admin-android-app/` directories were also moved there because they only contained incomplete/generated Android build material and no final APK files. Download routes expect APKs under `static/downloads/` when those packages are available.

## External Secrets

Build secrets are kept outside the project tree:

- `/var/backups/goshinsho/secrets/android-app/goshinsho-release.jks`

Do not copy keystores, service credentials, or `.env` files into Git.

## Backup Policy

Project backups live under `/var/backups/goshinsho/daily`.

Backups include runtime code, source data, `data/publication_sources`, support data, and active indexes. They exclude the Python virtual environment, bytecode, temporary rebuild staging, logs, exports, and other generated or discarded artifacts.
